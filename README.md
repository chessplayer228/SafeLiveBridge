# Safe LiveBridge (One UI 7 / 8 / 9 Edition)

Полнофункциональный нативный клон **LiveBridge** для смартфонов **Samsung Galaxy** под управлением **One UI 7, 8 и 9**, разработанный на Kotlin и Jetpack Compose.

Приложение преобразует любые стандартные уведомления (доставка еды, такси, таймеры, мессенджеры, плееры) в нативные живые активности (**Live Updates**) на экране блокировки Samsung (**Now Bar**) и в Always-On Display.

---

## 🌟 Ключевая эксклюзивная функция: Expander всех уведомлений

В оригинальном Samsung Now Bar отображается лишь одна узкая строка. В **Safe LiveBridge** реализован специальный механизм:
* **При нажатии на уведомление в Now Bar** открывается интерактивное всплывающее окно в стиле One UI со **списком всех активных уведомлений от этого приложения**.
* В этом окне можно:
  * Просмотреть полный текст каждого сообщения и время получения.
  * Видеть прогресс-бары заказов/загрузок в реальном времени.
  * Нажимать кнопки действий оригинального приложения (например: *«Ответить»*, *«Принять»*, *«Отследить заказ»*, *«Пауза»*).
  * Нажатием на уведомление сразу перейти к конкретному сообщению в приложении.
  * Смахнуть или закрыть отдельное уведомление крестиком.
  * Нажать *«Очистить все»* или *«Открыть приложение»*.

## 🚀 Все возможности LiveBridge в комплекте

1. **Трансляция в Samsung Now Bar:**
   * Поддержка системного разрешения `POST_PROMOTED_NOTIFICATIONS`.
   * Специальные метаданные для One UI Lockscreen.
   * Динамический прогресс (заказ такси, доставка, загрузки).
2. **Умный перехватчик OTP-кодов:**
   * Автоматически находит 4–8 значные коды подтверждения в SMS и мессенджерах.
   * Добавляет кнопку *«Скопировать код: XXXXXX»* прямо в плашку Now Bar и уведомление.
3. **Современный интерфейс в стиле One UI 9:**
   * Скругленные карточки (24–28dp), крупные заголовки, акцентный цвет Samsung Blue (`#0C66E4`).
   * Поддержка системной темной и светлой тем.
   * Интерактивное превью капсулы Now Bar прямо на главном экране.
4. **Менеджер приложений:**
   * Поиск по всем установленным приложениям.
   * Белый и черный списки (выбор приложений, которым разрешено появляться в Now Bar).
5. **Встроенный тестер Now Bar:**
   * Быстрая отправка тестовых уведомлений («Яндекс Еда 75%», «Яндекс Go Такси», «OTP Telegram») для моментальной проверки на экране блокировки без ожидания реальных заказов.
6. **Быстрые настройки (Quick Settings Tile):**
   * Плитка в шторке быстрых переключателей для включения/выключения моста в 1 тап.
7. **Устойчивость в фоне (Keep Alive Service):**
   * Предотвращает усыпление приложения агрессивным оптимизатором аккумулятора Samsung.

## 📦 Где взять готовый APK

Собранный и готовый к установке APK-файл находится в директории:
```
build-output/SafeLiveBridge-OneUI.apk
```

### Как установить на телефон Samsung:
1. Передайте файл `build-output/SafeLiveBridge-OneUI.apk` на смартфон (через USB, Quick Share, Telegram или Google Drive).
2. Разрешите установку из неизвестных источников и установите APK.
3. Откройте **Safe LiveBridge** и выполните 3 простых шага в мастере разрешений:
   * Предоставьте **Доступ к уведомлениям** (Notification Access).
   * Отключите ограничения расхода аккумулятора (**Не ограничено**).
   * В настройках экрана блокировки Samsung включите **Живые уведомления (Now Bar)**.
4. Перейдите во вкладку **«Тест Now Bar»**, нажмите кнопку теста, заблокируйте телефон — капсула появится на экране блокировки!
